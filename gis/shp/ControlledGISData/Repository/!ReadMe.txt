This folder contains various GIS Hanford files. Here is what's in each folder:

-Raster: raster files
-Symbology: .lyrx files to apply symbology to layers
-Vector: point, line, polygon files
 
Raster_Inventory.xlsx & Vector_Inventory.xlsx tables list the contents of Raster & Vector folder. Column description:

-Description: brief summary of the file
-Location: location of the folder/gdb within the subfolder
-FileName: name of the file
-Date Data Collected: date when the data was collected
-Notes: meta information

Well location data must be pulled from the Environmental Dashboard Application (EDA).

Files are the most up to date versions based on the "Date Data Collected" column. Previous versions will be placed in the "Archive" folder.
Files already on the network will have a Shortcut link provided to the files. "Shortcut" will be listed in the notes column when this occurs.

DO NOT EDIT ANY OF THE FILES IN THIS FOLDER. Save a copy of the file and work with the copy if you need to edit.
